❓ TROUBLESHOOTING

Issue: "Module not found"
→ Run: npm install --legacy-peer-deps

Issue: "TypeScript errors"
→ Ensure all screen exports are in index.ts files

Issue: "Navigation not working"
→ Check types.ts has all screen names defined

Issue: "Theme not applying"
→ Use useTheme() from react-native-paper in components
